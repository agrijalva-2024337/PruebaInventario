# SLCDevicesManagement

Sistema para el control e inventario de activos con funcionamiento multiempresa (Sistemas Logísticos y Corporativos, S.A.).

## Estructura del repositorio

| Ruta | Qué es |
| --- | --- |
| `src/SLCDM.*` | Backend .NET 8 (Clean Architecture) |
| `frontend/` | Interfaz web React + Vite |

## Frontend

Ver la guía en [`frontend/README.md`](frontend/README.md).

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```
